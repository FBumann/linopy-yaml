How five libraries scale on the same four models

Build a model and hand it to HiGHS, with run() never called. Every point is one process, best of three, on an idle machine. The parity gate passed on all six models: the two lanes agree on the objective to 0.0e+00 relative (fleet to 4.6e-16), so nothing here is fast because it built a different model.

Five libraries, four models, both axes logarithmic

Show

One panel per model and destination, one line per library, log on both axes — the only shape that shows a slope, and the slope is the claim. A table can say a library is behind at one size; only the curve says whether it is falling further behind or catching up.

The shaded band is that measurement's own rounds — the middle half of them, first quartile to third. It is not a confidence interval and not the spread across models: it is what this machine did to the same work nine times over. Two lines whose bands overlap are two numbers this run cannot tell apart, and a line that stops short of the others was refused by the harness's time budget rather than missing.

Quartiles rather than the full envelope on purpose: one nine-round measurement here read [1.18, 1.02, 1.07, 1.02, 1.02, 1.02, 1.06, 1.45, 9.97], so a min-to-max band would have drawn a single outlying round ten times the height of the model it belongs to.
